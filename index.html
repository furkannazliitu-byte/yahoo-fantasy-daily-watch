Daily Watch

A small, private tool for following one Yahoo Fantasy team, keeping a daily record of player statistics, and spotting meaningful changes in performance.

Single user · Read only · One personal league

Daily team snapshot

Reads the current roster and available player statistics from the user's Yahoo Fantasy league.

Performance trends

Compares fantasy points with the player's recent observations and highlights notable drops for review.

Private reports

Creates a dated report for the team owner. The tool is not a public service and has no other users.

Read-only by design

The tool requests only the data needed to analyze the owner's own roster and league settings. It does not change lineups, add or drop players, submit transactions, or share or sell league data. Reports and history are stored locally on the owner's computer.

Yahoo Fantasy data is provided by Yahoo. This independent personal project is not affiliated with or endorsed by Yahoo.
